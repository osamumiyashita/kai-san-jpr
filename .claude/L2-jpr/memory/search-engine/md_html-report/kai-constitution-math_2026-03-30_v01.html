1. MVC/SG100Y 最適化理論

1.1 基本定義

月次価値創造額 (Monthly Value Created) を以下で定義する:

MVC(t) = IC(t) × (ROIC(t) − WACC(t)) / 12 ここで: IC(t) ∈ ℝ₊ : 時刻 t における投下資本 ROIC(t) ∈ ℝ : 投下資本利益率 WACC(t) ∈ ℝ₊ : 加重平均資本コスト
定義 1.1 (SG100Y 汎関数)

SG100Y を以下の割引累積汎関数として定義する:

SG100Y[MVC] = ∫₀^{1200} MVC(t) · e^{−r(t)} dt 連続時間版: r(t) = WACC(t)/12 (月次割引率) 離散近似: SG100Y ≈ Σ_{t=0}^{1200} MVC(t) / (1 + WACC/12)^t

1.2 最適化問題の定式化

SG100Y の最大化問題を変分問題として定式化する:

maximize J[x] = ∫₀^T L(t, x(t), ẋ(t)) dt subject to: ẋ(t) = f(x(t), u(t), t) (状態方程式) g(x(t), u(t)) ≤ 0 (制約条件) x(0) = x₀ (初期条件) 状態変数 x = (IC, ROIC, WACC, S, C, Conf)ᵀ ∈ ℝ⁶ 制御変数 u = (投資決定, 人的資本配分, リスク管理)ᵀ

1.3 ハミルトン-ヤコビ-ベルマン方程式

動的計画法による最適性条件:

−∂V/∂t = max_u { L(t,x,u) + (∂V/∂x)ᵀ f(t,x,u) } V(t, x): 価値関数 (value function) 最適制御: u*(t) = argmax_u H(t, x, u, λ) ハミルトニアン: H = L(t,x,u) + λᵀ f(t,x,u) λ(t): 共役変数 (shadow price of capital)

1.4 定常状態と安定性

定理 1.1 (SG100Y 最適性の必要条件)

最適軌道 x*(t), u*(t) に対し、以下のポントリャーギン最大原理が成立する:

ẋ* = ∂H/∂λ (状態方程式) λ̇ = −∂H/∂x (共役方程式) 0 = ∂H/∂u (最適性条件) 横断条件: λ(T) = ∂Φ/∂x(T) ただし Φ: 終端コスト (terminal cost)

定常状態 x̄ において ROIC(x̄) = WACC(x̄) が成立するとき、MVC = 0 となり、これは経済的損益分岐点 (economic breakeven) を意味する。SG100Y 最大化はこの均衡からの正の乖離 ROIC − WACC > 0 を持続させる制御問題として解釈される。

2.3 GCC スコアの不変量

定義 2.2 (GCC 不変量)

リー群作用 φ: G × ℳ → ℳ のもとで不変な量:
