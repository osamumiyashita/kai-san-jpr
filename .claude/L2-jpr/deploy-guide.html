「黒い画面」とは？
パソコンに文字で命令を出す画面です。
普段はマウスでクリックして操作しますが、「黒い画面」ではキーボードで文字を打って命令します。
難しそうに見えますが、コピペするだけなので安心してください。

Windowsの「黒い画面」は2種類あります

① コマンドプロンプト（cmd）

黒い背景に白い文字。一番シンプル。

開き方:

  1. キーボードのWindowsキー（旗マーク ⊞）を押す
  2. そのまま cmd と3文字入力
  3. 「コマンドプロンプト」が表示される → クリック
  4. 黒い画面が開く！
このガイドではコマンドプロンプトを使います。どちらでも動きますが、これが一番シンプルです。

② PowerShell（パワーシェル）

青い背景のこともある。より高機能版。

開き方: Windowsキー → powershell と入力 → クリック

コマンドプロンプトと同じコマンドが使えます。こちらでもOKです。

管理者として実行（権限エラーが出た時）

「アクセスが拒否されました」と出たら：

  1. Windowsキー → cmd と入力
  2. 「コマンドプロンプト」を右クリック
  3. 「管理者として実行」をクリック
  4. 「はい」をクリック → 管理者権限の黒い画面が開く

Macの「黒い画面」

ターミナル（Terminal）

Macの「コマンドプロンプト」。名前が違うだけです。

開き方:

  1. Cmd + スペースを同時に押す（Spotlight検索）
  2. ターミナル と入力
  3. Enterを押す → ターミナルが開く

別の方法: Finder → アプリケーション → ユーティリティ → ターミナル

Bash（バッシュ）/ Zsh（ジーシェル）

ターミナルの「中で動いている言語」。気にしなくてOK。

古いMac = Bash / 新しいMac = Zsh。どちらでも同じコマンドが使えます。

コマンドの入力方法（全OS共通）

  1. このガイドの黒い枠の中のテキストを全選択（トリプルクリック or Ctrl+A）
  2. コピー（Ctrl+C / Cmd+C）
  3. 黒い画面に移動
  4. 貼り付け
    Windows: 黒い画面で右クリック（自動で貼り付け）
    Mac: Cmd+V
  5. Enterキーを押す → 実行される
注意: 黒い画面ではCtrl+Vが使えないことがあります（Windows）。
代わりに右クリックで貼り付けてください。

OS黒い画面の名前開き方貼り付け
Windowsコマンドプロンプト⊞ → cmd右クリック
WindowsPowerShell⊞ → powershell右クリック or Ctrl+V
MacターミナルCmd+Space → ターミナルCmd+V

「'git' は認識されていません」
原因: Gitが未インストール、またはPATHに未登録
対策: Step 1でGitをインストール → コマンドプロンプトを閉じて開き直す
「'node' は認識されていません」
原因: Node.jsが未インストール
対策: Step 2でNode.jsをインストール → 閉じて開き直す
「'python' は認識されていません」
原因: Pythonの「Add to PATH」チェック忘れ
対策: Pythonを再インストール。今度は必ず「Add python.exe to PATH」にチェック
「npm ERR! code EACCES」
原因: 管理者権限が不足
対策: Windows=「管理者として実行」/ Mac=sudoを先頭に付ける
「Authentication failed」
原因: GitHubにログインしていない
対策: ブラウザで github.com にログイン → もう一度コマンド実行
「repository not found」
原因: GitHubの招待を承諾していない
対策: メールで「Accept invitation」クリック。届いていなければ修さんに連絡
「destination path already exists」
原因: 既にインストール済み
対策: 更新するだけ → cd %USERPROFILE%\.claude && git pull
「pip: command not found」
原因: PythonのPATH設定が不足
対策: Pythonを再インストール（「Add to PATH」必須）。Macはpip3で実行
「SSL certificate problem」
原因: 会社のネットワークがSSL検査をしている
対策: IT部門に「git, npm のSSL通信を許可してほしい」と依頼

よくある質問（FAQ）

安心してお使いいただくために
J-Phoenix Research
Q: パスワードは必要ですか？
A: いいえ。GitHubとClaudeの認証のみです。Kai-san自体に別のパスワードはありません。
Q: 2台目のPCにも入れられますか？
A: はい。同じ手順を別のPCで実行するだけです。何台でもOKです。
Q: アンインストールするには？
A: .claudeフォルダを削除するだけです。他に何も残りません。レジストリも汚しません。
Windows: rmdir /s %USERPROFILE%\.claude
Mac: rm -rf ~/.claude
Q: 私のデータはどこに保存されますか？
A: あなたのPCの中だけです。JPRのサーバーには一切送信されません。データ主権はあなたにあります。
Q: 料金はかかりますか？
A: Claude MAXプラン（定額制・月額固定）が必要です。従量課金は一切発生しません。プランの詳細は修さんに確認してください。
Q: インターネットは常に必要ですか？
A: Claude利用時はインターネットが必要です。ただしOllamaを入れれば、一部の機能はオフラインでも動作します。
Q: 会社のセキュリティポリシーに抵触しませんか？
A: Kai-sanはローカル動作のみ。外部サーバーへのデータ送信はありません。IT部門には「GitからCLIツールを使用する」と説明してください。
Q: Kai-sanが暴走することはありませんか？
A: 海憲法（Kai Constitution）で行動が厳密に制御されています。人間の最終意思決定権が保証されています。
Q: 更新はどうすればいいですか？
A: cd %USERPROFILE%\.claude && git pull で最新版に更新できます。将来は自動化予定です。
Q: 他の人が私のKai-sanを使えますか？
A: いいえ。あなたのPCにインストールされ、あなたのClaudeアカウントでのみ動作します。
Q: WindowsとMacで機能差はありますか？
A: 基本的にありません。同じKai-sanが動きます。一部コマンドの書き方が異なるだけです。
Q: 古いPCでも動きますか？
A: Windows 10以降、macOS 12以降であれば動作します。メモリ8GB以上推奨です。
